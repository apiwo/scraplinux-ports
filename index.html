What's here

This is the actual ports/ tree - the same one ScrapLinux's own build system reads from, organized by repo (main, extra, base, kernels, profile, nonfree, alt-nonfree, multilib), one directory per package holding a plain POSIX sh recipe: name, version, source, a build() and a package() function.

Clone this repo to get a working ports/ checkout, or build one recipe directly with scraps add -s <name>.
